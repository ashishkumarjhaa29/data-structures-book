# Data Structures from First Principles

This is my personal data structures book.

The goal is not to memorize definitions, but to understand data structures through:

- memory layout
- invariants
- operations
- implementation details
- dry runs
- edge cases
- complexity analysis
- problem patterns

The main implementation language is C, because C forces clear thinking about memory, pointers, allocation, and ownership.

C++ STL notes may be added later for comparison.
